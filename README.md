КРАТКАЯ ИНСТРУКЦИЯ ПО ЗАПУСКУ ПРОЕКТА

1. TELEGRAM
   - Создать бота через @BotFather -> получить BOT_TOKEN.
   - Узнать свой ID через @userinfobot -> это OWNER_CHAT_ID.

2. НАСТРОЙКА .ENV
   - Переименовать .env.example в .env.
   - Вписать BOT_TOKEN и OWNER_CHAT_ID.
   - В GIT_REPO_URL вставить ссылку на ваш ПРИВАТНЫЙ репозиторий, используя токен доступа (PAT) от GitHub: https://<ТОКЕН>@github.com/логин/репо.git
   - Выбрать модель OLLAMA_MODEL (например, qwen2.5:7b). Если мало ОЗУ, взять модель на 3b.

3. ПАПКА VAULT
   - Создать пустую папку "vault" в корне проекта (рядом с docker-compose.yml).

4. ЗАПУСК DOCKER
   - Открыть терминал в папке проекта.
   - Выполнить: docker-compose up -d --build
   - Дождаться, пока все контейнеры запустятся.

5. СКАЧАТЬ LLM МОДЕЛЬ (ОБЯЗАТЕЛЬНО)
   - Выполнить в терминале: 
     docker exec -it project-ollama-1 ollama run qwen2.5:7b
     (замените qwen2.5:7b на вашу модель из .env)
   - Дождаться скачивания. Выйти командой /bye.

6. ТЕСТ
   - Написать боту /start.
   - Отправить голосовое сообщение.
   - Проверить папку vault и ваш GitHub-репозиторий.

ВАЖНО ЗНАТЬ:
- Google Calendar из ТЗ заменен на задачи в Obsidian (формат Markdown). 
- Для работы нужен ПК/сервер с минимум 8-16 ГБ ОЗУ (из-за Whisper и Ollama).
- Если бот завис: смотрите логи командой docker-compose logs -f worker
